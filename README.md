# Neural Monte Carlo Denoiser
This branch contains an implementation of the SIGGRAPH '17 paper [Interactive Reconstruction of Monte Carlo Image Sequences using a Recurrent Denoising Autoencoder](https://dl.acm.org/doi/10.1145/3072959.3073601) by Chaitanya et al. This uses a U-Net like architecture with recurrent connections between encoder blocks, allowing neural representations and gradients to propagate across time - as such, the network is trained with BPTT. The model takes 1 SPP albedo demodulated radiance, view-space normals and depth in order to predict the per-pixel denoised radiance directly in real-time.
